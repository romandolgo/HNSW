# HNSW

Реализация NSW и HNSW (Hierarchical Navigable Small World) для приближённого поиска ближайших соседей на `numpy`.

Векторы базы должны быть уникальными: при дубликатах индексы выдают `ValueError`.
Ограничения степени `m_max` и `m_max0` должны быть не меньше `m`.

## Структура

```
.
├── graph.py        # общие части: search_layer, select_simple, select_heuristic
├── nsw.py          # NSW — однослойный граф
├── hnsw.py         # HNSW — многослойный граф
├── metrics.py      # евклидово расстояние
├── bruteforce.py   # точный kNN перебором, используется как эталон
├── data.py         # загрузка Pendigits с прогресс-баром
├── bench.py        # подсчёт recall@k, числа вычислений расстояния, sweep по параметрам
└── compare.py      # сравнение NSW и HNSW: таблица и один график
```

## Запуск

Зависимости ставятся через [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```

Пример использования:

```python
import numpy as np
from hnsw import HNSW

points = np.random.default_rng(0).uniform(size=(1000, 2))

index = HNSW(points, m=8, ef_construction=40, seed=0)
index.build()

index.search(np.array([0.5, 0.5]), k=10, ef=50)  # [(distance, index), ...]
```

Сравнить NSW и HNSW при `m = 4, 8, 16` и `ef = 10, 20, 40, 80, 160`:

```bash
uv run python compare.py
```

Скрипт выводит таблицу и сохраняет интерактивный график Plotly в `figures/pendigits.html`.
HTML открывается в браузере без интернета. При наведении на точку показываются
`ef`, recall и число вычислений расстояния; линии можно скрывать нажатием на легенду.
По оси X — среднее число вычислений расстояния на запрос (меньше — дешевле),
по оси Y — recall@10 относительно полного перебора. Каждая точка соответствует
одному `ef`; цвет задаёт `m`, сплошные линии — HNSW, пунктирные — NSW.
Это оценка стоимости поиска, а не замер времени. Используется
[Pendigits из UCI](https://archive.ics.uci.edu/dataset/81/pen+based+recognition+of+handwritten+digits):
7494 точки базы в 16 измерениях и 300 запросов из отдельной тестовой части
(выбор запросов с `seed=0`). Метка цифры исключается из признаков;
координаты переводятся в `float` и делятся на 100.
При первом запуске данные скачиваются в `datasets/pendigits/`, затем используются
локальные файлы. Папки `datasets/` и `figures/` не попадают в Git.
Число запросов задаётся константой `QUERIES` в `compare.py`.
Оба индекса используют одну
эвристику выбора соседей и одинаковый предел степени на нижнем слое (`2*m`).

## AI Usage

AI использовался для загрузки данных (`data.py`), скрипта сравнения и графика (`compare.py`), бенчмарк-обвязки и части этого ридми :).

Основная реализация NSW и HNSW находится в `graph.py`, `nsw.py`, `hnsw.py` и `metrics.py`.
