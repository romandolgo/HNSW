# NSW и HNSW

## Структура проекта

```text
├── graph.py        # Поиск внутри слоя и стратегии выбора соседей
├── nsw.py          # Однослойный индекс NSW
├── hnsw.py         # Многослойный индекс HNSW
├── metrics.py      # Евклидово расстояние
├── bruteforce.py   # Точный поиск полным перебором
├── data.py         # Загрузка и подготовка Pendigits
├── bench.py        # Перебор настроек, подсчёт метрик и вывод таблиц
└── compare.py      # Сравнение алгоритмов и построение графика
```

## Как работает compare.py

Скрипт загружает Pendigits и выбирает 300 тестовых запросов с `seed=0`.
Затем сравнивает NSW и HNSW с простым выбором ближайших соседей
(`select_simple`) и с эвристикой (`select_heuristic`).

Для каждого варианта строятся индексы с `m = 4, 8, 16`
и `ef_construction=100`. Через `bench.sweep` проверяются значения
`ef = 10, 20, 40, 80, 160`. Измеряются recall@10 относительно полного
перебора и среднее число вычислений расстояния на запрос.

Результаты выводятся в четыре таблицы и сохраняются в
`figures/pendigits.html`. На графике слева показан простой выбор соседей,
справа — эвристика. По оси X отложено число вычислений расстояния,
по оси Y — recall@10. Цвет задаёт `m`, сплошные линии обозначают HNSW,
пунктирные — NSW.

Запуск:

```bash
uv run python compare.py
```
